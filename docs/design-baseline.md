## Approved command-deck iteration

Evan's August 2 feedback approved the parallax concept, station glows, station positions, and surrounding site while identifying the isometric floor and Red character perspective mismatch as the problem to solve. The August 2 default therefore used a top-down Scout command ship over a celestial parallax with Red's eight directional walk cycles.

This is a deliberate mode-specific evolution of the canvas, not a rewrite of the protected page hierarchy:

- The hero, signal card, section titles, palette, typography, conventional résumé, and footer principle remain unchanged.
- Literal purpose labels now accompany the six protected station names so a visitor can understand each destination immediately.
- The default canvas identity is `EWL // COMMAND DECK`; the mountain and procedural comparisons retain `EWL // CAREER ARCHIVE`.
- Static directional Red frames replace the breathing-style idle loop until a calmer neutral idle is available.
- `?background=mountains` preserves the liked Stormy Mountains experiment and its isometric platform.
- `?background=baseline` continues to preserve the original procedural archive.
- Decorative motion remains frozen for reduced-motion users, and hiding the game still pauses Phaser.

## August 3 launch command bridge

Evan's follow-up correctly identified that the top-down ship still asked an orthographic character to inhabit the wrong camera. The launch scene therefore pivots the default canvas to a fixed-camera 2.5D command room while preserving the August 2 ship at `?background=space`.

The launch composition protects the parts Evan explicitly liked:

- Red remains the default avatar in his preferred red shirt.
- The six glows, protected station names, literal résumé-purpose labels, and surrounding page layout remain intact.
- Red walks left and right along one foreground lane. There is no camera scroll, depth scaling, or fake parallax on the flattened room art.
- All six destinations remain visible at once in a left-to-right recruiter-friendly menu.
- E, Enter, direct pointer selection, three-button touch controls, and the semantic terminal directory all reach the same résumé panels.
- The ambient room animation uses a repaired seamless ping-pong loop. The sharp still is always underneath it and completely replaces it for reduced motion or playback failure.
- The mountain and procedural modes remain unchanged at their existing comparison URLs.
